DarkRaw portable mode

While this file sits next to the program (DarkRaw-LD.exe), DarkRaw keeps its
preferences, brush presets, crash-recovery autosaves and startup state in the DarkRawData folder
beside it, and writes nothing to %APPDATA% or %LOCALAPPDATA%. Copy the whole folder to move DarkRaw
with its settings.

Delete this file to use the normal per-user folders instead: %APPDATA%\DarkRaw for settings
and %LOCALAPPDATA%\DarkRaw\Recovery for crash-recovery autosaves. If DarkRawData can't be
written (for example on a read-only drive), DarkRaw says so and uses those folders instead.
